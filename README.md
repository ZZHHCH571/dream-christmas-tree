# 🎄 梦幻星河 3D 圣诞树（单文件 HTML 开源模板）

专为自媒体分享与亲友圣诞惊喜打造的**单文件 3D 互动圣诞树**，零构建、零外部图片/音频依赖，支持直接发微信用手机浏览器打开，也适合拖进 **豆包电脑端「工作」模式** 一句话定制专属名字、祝福语与主题色。

## 特性亮点
- **7 层垂坠松枝 3D 粒子树**：基于 Three.js + 自定义 GPU Shader，粒子晶莹通透、立体饱满不糊屏。
- **78 颗真实 3D 金属质感挂饰 + 双螺旋流光星带 + 璀璨树顶星芒**。
- **6 张 3D 悬浮拍立得照片/祝福卡**：支持点击右上角相册图标一键上传 1~6 张本地照片（自动 1:1 居中裁剪与轻量化压缩），点击 3D 卡片可放大查看高清合照，导出专属 `.html` 时照片自动内嵌、发微信零裂图。
- **一键星河魔法**：点击「✦ 散成梦幻星河」或双击屏幕，整棵树与卡片丝滑炸散成 3D 银河星云，再次点击聚合成树。
- **3 套高定配色一键切换**：梦幻玫瑰粉金 / 高定祖母绿暖金 / 冰雪极光蓝紫。
- **水晶八音盒《Jingle Bells》**：Web Audio API 纯代码合成，正确节拍配柔和低音和声。
- **一键自定义名字与导出**：点击右上角编辑图标可修改名字和祝福语，直接导出新的专属 `.html` 文件发给朋友。

## 用豆包电脑端「工作」模式快速定制
1. 打开电脑端豆包，切换至 **「工作」** 模式；
2. 将 `index.html` 拖入工作区，输入：
   > 请帮我把名字改成「阿宁」，祝福语改成「圣诞快乐，天天开心」，默认配色改成 `rose`（梦幻玫瑰粉金），生成新的 html 文件。
3. 生成后点击文件夹图标，将 `.html` 直接拖进电脑微信发给闺蜜/对象，对方用手机浏览器打开即可拆开惊喜。
